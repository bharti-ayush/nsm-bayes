This folder contains the code necessary for reproducing the results of the paper "Generalized Bayesian Likelihood-Free Inference" by Pacchiardi, Khoo and Dutta.

The folder `GenBayes_LikelihoodFree_ScoringRules` contains code to reproduce the experiments with PM-MCMC, while the `GenBayes_LikelihoodFree_ScoringRules_SGMCMC` folder contains the code for reproducing the experiments with SG-MCMC.
